# hwu81.github.io

Personal homepage of Hao Wu (吴昊), Institute of Natural Sciences and School of
Mathematical Sciences, Shanghai Jiao Tong University — <https://hwu81.github.io/>

Static HTML and one stylesheet.

| File | |
|---|---|
| `index.html` | English page |
| `zh.html` | 中文页 |
| `style.css` | shared stylesheet |
| `portrait-2026.jpg` | portrait |
| `favicon.svg`, `.nojekyll` | tab icon; tells Pages to serve files as-is |

Edit the text directly in the two HTML files. They are independent — an English change goes in `index.html`, the Chinese one in `zh.html` — and the `[en] [中文]` links in the header are plain links between them.

Fonts come from Google Fonts as an enhancement only: where they are blocked the page falls back to system fonts and the layout is unchanged.
